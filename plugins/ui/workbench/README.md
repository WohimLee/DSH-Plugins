# dsh-workbench

为 DSH 原生界面增加常驻功能栏，提供项目导航、原生对话和右侧工具标签。继续使用 DSH 原生 harness、项目会话、模型选择、工具和审批流程，与 dsh-codex 模型插件独立。

## 源码组织评估

采用 workspace，不使用 Git submodule。插件由本仓库统一维护，需要与构建、目录和宿主兼容验证同步修改，目前没有独立团队、仓库权限或外部上游源码同步需求。模块在包内组织，一个安装包独立发布；维护团队、权限边界或源码来源发生变化时重新评估。

## 工作台

- 最左侧功能栏集中了返回对话的 Home、插件、自动化任务及其他已注册的全局面板。更多面板可以打开入口或调整其在功能栏的固定状态。项目与会话侧栏只在 Home 显示，由原生顶部开关和 `⌘B` 控制。进入工具页时，内容区使用侧栏让出的空间。
- 桌面宽窗将原生账号与设置菜单放在最左功能栏底部，使用其上方的双向箭头切换工作台和原生工作区列表。窄窗沿用抽屉底部入口。原生搜索、归档与第三方行内操作仍可从原生列表使用。
- 功能栏随插件面板注册、卸载和语言变化更新；第三方面板图标使用原生 Component Factory 渲染。
- 使用正式 shell.overlay 插槽与稳定 data-slot 样式锚点，不替换 root，不重复声明原侧栏子插槽。项目侧栏继续由原生布局控制，桌面宽度下可与功能栏独立折叠。
- 窄窗口隐藏额外功能栏，使用原生导航抽屉。卸载移除导航贡献、样式和文档标记。

侧栏品牌行容纳活动铃铛和新建分区，新建会话单独占一行。项目与直属会话的标题左对齐，行尾为可见的状态和操作留出空间。100% 缩放下，宽窗功能栏宽 44.5 px，项目列表栏默认宽 291 px，可拖动调整。项目和会话列表使用 14 px 文字，桌面会话标题使用 13 px 文字。对话正文跟随宿主字号设置。

### 项目与会话

- 点击分区或项目标题展开、收起。项目可以嵌套，子项目在会话之前展示。每个项目每次展开时显示前 10 条自己的会话，置顶计入。用 Show more 查看剩余会话。
- 新建分区或项目时，在对应列表顶部行内命名。按 Enter 或点击创建提交，Escape 或留空时点别处取消，输入了名称的行失焦后保留草稿。项目的文件夹按钮直接进入创建流程，提交名称后选择目录。
- Recents 下方固定显示 Archived，可独立折叠。归档会话显示在这里，点击会话行的取消归档按钮即可恢复到原分组。Recents 标题行提供添加项目和新建会话。自定义分区、项目和会话通过右键或 `…` 打开各自的菜单。自定义分区支持重命名、添加项目和移除。项目支持置顶、重命名、移动分区、在文件管理器中显示、归档直属会话和移除工作区注册。会话支持重命名、编辑目录、置顶、未读、移动、Fork、复制标题或 ID 和归档。
- 普通和已归档会话都可以从菜单选择「永久删除」，确认后删除对应的本机 JSONL 存档。运行中的会话需先结束。空闲且无写入占用的会话立即删除，宿主仍持有写锁时会显示下次启动删除的提示。
- 新建会话直接打开 DSH 的空白对话页。顶部和 Recents 的入口默认使用当前或最近的项目，项目行的入口使用该项目。打开空白页后可用原生项目选择器切换项目。首条消息被宿主记录后，会话出现在侧栏，初始标题来自这条消息。
- 项目与会话的右键菜单和行尾 `…` 使用同一套排版。100% 缩放下，菜单文字 13 px，同组行高 24 px，跨分隔线的相邻行相距 35 px。项目菜单的 Edit 打开项目编辑弹窗，悬停在源文件夹行上可查看完整路径。Desktop 的 Add folder 直接打开系统文件夹选择器。Save 保存名称和源文件夹，Cancel、关闭、Escape 或点击弹窗外部放弃草稿。项目名称由宿主保存，源文件夹关联保存在当前客户端，可从摘要打开。DSH 会话继续使用宿主指定的工作目录。
- 从会话行的右键或 `…` 菜单选择 Rename，在弹窗里改名。弹窗打开时选中原有标题，保存后更新侧栏，取消或按 Escape 可撤回编辑。
- 会话菜单中的 Edit 调用 DSH 原生工作目录服务，为后续操作设置有效目录，重启后可恢复。项目归属、原始项目根和已启动进程的目录分别由各自的宿主机制维护。
- 拖动标题行可重排分区、项目和会话。分区也能放到列表末尾的空白处。将项目拖入分区或项目行的中间可调整父级，拖到项目行上下边缘可调整同级顺序。会话可以拖入其它项目，仍使用原来的 DSH 会话和执行目录。移动项目时随之移动其子项目。
- 默认按会话最新活动排序。浏览会话不改变顺序。DSH 记录用户消息时，将该会话移到置顶组或未置顶组的最前面。点击 Pin Chat 置顶，再点常亮的图标取消，取消后的会话排在未置顶组首位。
- 归组和顺序保存在对应 Desktop 或 Web 客户端的本地存储。置顶状态由 DSH 宿主管理。

### 右栏与缩放

- 右侧工具区复用 DSH 原生标签的打开、切换、关闭和全屏。New tab 可搜索当前会话工作目录中的文件，也可输入带 `https://` 或 `http://` 的网址，交给原生 Browser 标签。文件搜索使用宿主查询，默认遵循 Git 忽略规则、过滤隐藏文件，最多展示 12 个文件。终端、浏览器、文件及其他已注册工具按宿主提供的能力启用。
- 顶部的固定摘要显示项目、变更、从当前会话创建的聊天、子代理和项目源文件夹。点击 Subagents 在右栏查看运行中和已完成的子代理，包括嵌套子代理；其他状态单列。点击本地子代理进入其历史记录，返回键回到列表，外部执行标记为无本地记录。Share 使用宿主提供的 Liveshare 入口，Changes 使用宿主 Forge 扩展提供的本地变更标签。缺少提供方时，对应入口呈禁用状态。
- macOS Desktop 用 `⌘ -` 或 `⌘ _` 缩小，`⌘ =` 或 `⌘ +` 放大。内容区、侧栏和工具面板一起按 10% 调整，范围 70%–150%。右上角显示比例与重置按钮，停用插件后恢复原生字号快捷键。

## 开发与安装

当前开发基线为 DSH `0.2.2-rc.5`、Cordis `4.1.0`、React `18.3.1`，共享宿主模块实例。

```sh
pnpm check:dsh-version --require-desktop
pnpm --filter dsh-workbench check
pnpm --filter dsh-workbench test:host
pnpm --filter dsh-workbench pack --pack-destination /tmp
```

Desktop 通过应用插件页安装生成的 tarball。自动验证使用隔离 DSH_HOME，不改动日常 profile、不发送模型请求。运行状态和验证边界见 plugin.meta.json；不能将 Web 验证当作 Desktop 实际交互验收。

`test:host` 需要本机已安装 Google Chrome；其它 Chromium 可通过 `DSH_TEST_BROWSER_EXECUTABLE` 指定。测试创建独立的探针插件和合成取消历史，用浏览器实际操作会话及第三方面板。可设置 `DSH_TEST_ARTIFACTS` 输出截图，测试结束会清理临时宿主和浏览器。

## 会话动态

Home 侧栏顶部的铃铛可在项目列表与活动列表之间切换。后台会话完成时行尾显示未读蓝点，运行中显示转圈；打开对应会话清除未读。活动列表将运行中和未读会话列在最前，其余按日期展示。可见行从宿主读取已有的回复摘要。
