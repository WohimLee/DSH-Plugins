# dsh-workbench

为 DSH 原生界面增加常驻功能栏，提供项目导航、原生对话和右侧工具标签。继续使用 DSH 原生 harness、项目会话、模型选择、工具和审批流程，与 dsh-codex 模型插件独立。

## DSH 原生行为与接入方式

- **原生行为**。左栏「Workspaces / 工作区」由 `@deepseek-ai/dsh-client-ui-workspace` 的 `WorkspaceBrowser` 提供，注册在 `sidebar.workspaces`，负责浏览原生项目和会话。 [宿主注册源码](https://github.com/deepseek-ai/deepseek-harness/blob/ca33fd6843b205e279c7ccb6cb73a472c78f5760/packages/client/ui-workspace/src/client/index.ts#L378-L395)
- **接入方式**。Workbench 在 `shell.overlay` 用 `id: 'dsh-workbench:activity'` 添加功能栏，并以 `priority: -100` 覆盖 `sidebar.workspaces` 和 `sidebar.brand.name`。列表读取宿主项目和会话，通过 `uiWorkspace` 打开会话，通过 `workspaces` 更新置顶。切回原生列表时撤销列表覆盖。停用插件会移除功能栏并恢复这两个插槽的原生条目。 [客户端注册](src/client/index.tsx) · [列表切换](src/client/workspace/view.tsx)
- **验证证据**。见[验证记录](#验证记录)和 [plugin.meta.json](plugin.meta.json)，其中有 DSH `0.2.2-rc.5` 的隔离 Web 热启停及 Desktop 列表切换证据。

## 源码组织评估

采用 workspace，不使用 Git submodule。插件由本仓库统一维护，需要与构建、目录和宿主兼容验证同步修改，目前没有独立团队、仓库权限或外部上游源码同步需求。模块在包内组织，一个安装包独立发布；维护团队、权限边界或源码来源发生变化时重新评估。

## 工作台

- 最左侧功能栏集中了返回对话的 Home、插件、自动化任务及其他已注册的全局面板。更多面板可以打开入口或调整其在功能栏的固定状态。项目与会话侧栏只在 Home 显示，由原生顶部开关和 `⌘B` 控制。进入工具页时，内容区使用侧栏让出的空间。
- 桌面宽窗将原生账号与设置菜单放在最左功能栏底部，使用其上方的双向箭头切换工作台和原生工作区列表。窄窗沿用抽屉底部入口。原生搜索、归档与第三方行内操作仍可从原生列表使用。
- 功能栏随插件面板注册、卸载和语言变化更新；第三方面板图标使用原生 Component Factory 渲染。
- 使用正式 shell.overlay 插槽与稳定 data-slot 样式锚点，不替换 root，不重复声明原侧栏子插槽。项目侧栏继续由原生布局控制，桌面宽度下可与功能栏独立折叠。
- 窄窗口隐藏额外功能栏，使用原生导航抽屉。卸载移除导航贡献、样式和文档标记。

侧栏品牌行容纳活动铃铛和会话搜索，新建分区单独占一行。项目与直属会话的标题左对齐，行尾为可见的状态和操作留出空间。100% 缩放下，宽窗功能栏宽 52 px，项目列表栏默认宽 283.5 px，两栏合计 335.5 px，可通过拖动调整项目列表栏。侧栏项目名为 13.5 px，会话行标题为 13.6 px、字重 430、行高 20 px，优先使用用户配置的字体，默认使用系统 UI 字体回退。对话区顶栏标题为 12.5 px。聊天消息在 100% 缩放下使用 13 px 字号和 24 px 行高，表格使用 12 px 字号和 23 px 行高。已完成轮次的耗时行和工具调用摘要使用 14 px。消息、耗时和工具调用摘要的字号随 Workbench 缩放调整。 助手正文与工具调用摘要使用系统无衬线字体栈，在 macOS 选择 SF Pro 和系统中文回退；摘要字重为 430。

桌面指针模式下，100% 缩放的草稿和占位文字使用 13.5 px 字号与 24 px 行高。聊天中「改动文件」卡片的标题、文件名和展开文字使用 14 px，增删统计使用 13 px，桌面文件行高为 36 px。悬停预览使用 12 px 代码和行号，沿用宿主 22 px 的差异行高。用户消息气泡在深色主题使用宿主调色板的深蓝，在浅色主题使用原生浅蓝。样式通过原生 DOM 标记在 Workbench 启用时挂载。 [对话样式](src/client/appearance/conversation.ts)

宿主默认将单张用户图片显示为大图卡。Workbench 在 `conversation.chat.user.images` 请求原生 `conversation.images.content` 以 64 px 紧凑方块渲染用户图片。图片加载和原图预览继续由宿主负责。助手图片和输入框草稿保留各自的原生入口，停用 Workbench 后用户图片恢复宿主默认尺寸。

### 项目与会话

- 点击分区或项目标题展开、收起。项目图标随状态在圆角打开和闭合文件夹之间切换。项目可以嵌套，子项目在会话之前展示。每个项目每次展开时显示前 10 条自己的会话，置顶计入。用 Show more 查看剩余会话。
- 新建分区在侧栏行内命名。品牌行的放大镜打开会话搜索，按普通未归档会话的标题、项目或 ID 匹配。宿主启用全文索引时，通过 `sessions.search` 查找正文。选择结果或按 Enter 打开匹配会话，Escape 或点击外部关闭搜索。点击「添加项目」或「添加子项目」直接打开创建弹窗，填写名称并添加至少一个源文件夹后才能创建。第一个文件夹默认标为 Primary；悬停在其他目录上或用键盘聚焦时，可用 Make primary 切换，不改变列表顺序。创建时以选中的主目录为项目工作目录，其他源文件夹可从摘要打开。Cancel、关闭、Escape 或点击弹窗外部都会放弃草稿；侧栏仅在创建成功后显示新项目。
- Recents 下方固定显示 Archived，可独立折叠。归档会话显示在这里，点击会话行的取消归档按钮即可恢复到原分组。Recents 标题行提供添加项目和新建会话。自定义分区、项目和会话通过右键或 `…` 打开各自的菜单。自定义分区支持重命名、添加项目和移除。项目支持置顶、重命名、移动分区、在文件管理器中显示、归档直属会话和移除工作区注册。会话支持重命名、编辑目录、置顶、未读、移动、Fork 和归档。会话菜单显示操作图标和当前会话可用的宿主快捷键。悬停带箭头的菜单项，在旁边打开子菜单，也可用方向键进入及返回。Copy 可复制标题、会话 ID 和有效工作目录，并复用宿主提供的 Markdown 复制动作。会话深链接由支持该能力的 Desktop 提供。
- 未读会话的行尾显示蓝点。桌面指针悬停时显示行尾操作，移开后蓝点恢复。打开会话可清除未读。
- 子代理运行和历史记录从父会话的 Subagents 查看。项目、Recents、Archived 和活动列表展示普通会话。
- 「移除项目」和项目编辑中的「移除本地项目」共用确认弹窗。确认后删除侧栏直接归入该项目的会话，含归档会话。已排定重启删除的会话先归档。项目目录、文件和子项目会保留。
- 普通和已归档会话都可以从菜单选择「永久删除」，确认后删除对应的本机 JSONL 存档。运行中的会话需先结束。空闲且无写入占用的会话立即删除，宿主仍持有写锁时会显示下次启动删除的提示。
- 新建会话直接打开 DSH 的空白对话页。Recents 的入口默认使用当前或最近的项目，项目行的入口使用该项目。打开空白页后可用原生项目选择器切换项目。首条消息被宿主记录后，会话出现在侧栏，初始标题来自这条消息。
- 未分组会话行尾的「新建会话」和右键菜单使用 Workbench 专用的默认工作目录创建会话，归入侧栏的未分组会话。「移除分组」先显示数量与不可撤销提示，确认后删除列表中的未分组会话。此后可从 Recents 的菜单新建未分组会话或恢复分组。
- 项目与会话的右键菜单和行尾 `…` 使用同一套排版。100% 缩放下，菜单文字 13 px，同组行高 24 px，跨分隔线的相邻行相距 35 px。项目菜单的 Edit 打开项目编辑弹窗，悬停在源文件夹行上可查看完整路径。Desktop 的 Add folder 直接打开系统文件夹选择器。Save 保存名称和源文件夹，Cancel、关闭、Escape 或点击弹窗外部放弃草稿。项目名称由宿主保存，源文件夹关联保存在当前客户端，可从摘要打开。DSH 会话继续使用宿主指定的工作目录。
- 从会话行的右键或 `…` 菜单选择 Rename，在弹窗里改名。弹窗打开时选中原有标题，保存后更新侧栏，取消或按 Escape 可撤回编辑。
- 会话菜单中的 Edit 调用 DSH 原生工作目录服务，为后续操作设置有效目录，重启后可恢复。项目归属、原始项目根和已启动进程的目录分别由各自的宿主机制维护。
- 拖动标题行可重排分区、项目和会话。分区也能放到列表末尾的空白处。将项目拖入分区或项目行的中间可调整父级，拖到项目行上下边缘可调整同级顺序。会话可以拖入其它项目，仍使用原来的 DSH 会话和执行目录。移动项目时随之移动其子项目。
- 默认按会话最新活动排序。浏览会话不改变顺序。DSH 记录用户消息时，将该会话移到置顶组或未置顶组的最前面。点击 Pin Chat 置顶，再点常亮的图标取消，取消后的会话排在未置顶组首位。
- 归组和顺序保存在对应 Desktop 或 Web 客户端的本地存储。置顶状态由 DSH 宿主管理。

### 右栏与缩放

- 右侧工具区复用 DSH 原生标签的打开、切换、关闭和全屏。New tab 可搜索当前会话工作目录中的文件，也可输入带 `https://` 或 `http://` 的网址，交给原生 Browser 标签。文件搜索使用宿主查询，默认遵循 Git 忽略规则、过滤隐藏文件，最多展示 12 个文件。终端、浏览器、文件及其他已注册工具按宿主提供的能力启用。
- 顶部的会话摘要按当前会话显示项目文件夹、Forge 本地变更、创建的聊天和子代理。各组可展开和收起。Forge 报告的检出目录与侧栏项目不同，且能确定检出根时，本地变更显示在该检出目录分组。通过 `conversation.hero.frame` 在对话正文旁挂载摘要。对话区域宽度至少 1020 px 时，正文和输入框在剩余宽度内重新居中；更窄时摘要覆盖在对话右上方。项目源文件夹显示单行名称，悬停查看完整路径。展开 Subagents 可查看每个子代理的图标与状态，包括嵌套子代理。选择本地子代理会在右栏打开其历史记录，返回键回到右栏的完整列表。外部执行标记为无本地记录。Share 使用宿主提供的 Liveshare 入口，Changes 使用宿主 Forge 扩展提供的本地变更标签。缺少提供方时，对应入口呈禁用状态。
- macOS Desktop 用 `⌘ -` 或 `⌘ _` 缩小，`⌘ =` 或 `⌘ +` 放大。内容区、侧栏和工具面板一起按 10% 调整，范围 70%–150%。右上角显示比例与重置按钮，停用插件后恢复原生字号快捷键。

## 开发与安装

当前开发基线为 DSH `0.2.2-rc.5`、Cordis `4.1.0`、React `18.3.1`，共享宿主模块实例。

```sh
pnpm check:dsh-version --require-desktop
pnpm --filter dsh-workbench check
pnpm --filter dsh-workbench test:host
pnpm --filter dsh-workbench pack --pack-destination /tmp
```

Desktop 通过应用插件页安装生成的 tarball。自动验证使用隔离 DSH_HOME，不改动日常 profile、不发送模型请求。运行状态和验证边界见 plugin.meta.json；不能将 Web 验证当作 Desktop 实际交互验收。

`test:host` 需要本机已安装 Google Chrome；其它 Chromium 可通过 `DSH_TEST_BROWSER_EXECUTABLE` 指定。测试创建独立的探针插件和合成取消历史，用浏览器实际操作会话及第三方面板。可设置 `DSH_TEST_ARTIFACTS` 输出截图，测试结束会清理临时宿主和浏览器。

## 会话动态

Home 侧栏顶部的铃铛可在项目列表与活动列表之间切换。后台会话完成时行尾显示未读蓝点，运行中显示细灰圆环；打开对应会话清除未读。活动列表将运行中和未读会话列在最前，其余按日期展示。可见行从宿主读取已有的回复摘要。

0.3.0 在 DSH `0.2.2-rc.3` 与 Chrome `157.0.8103.79` 通过隔离宿主测试，覆盖顶部新建分区、面板去重、第三方导航、真实工作目录查询及预览、右栏全屏、归组重启恢复和热启停。macOS Desktop 同版本实测升级后热加载、顶部新建分区弹层、`⌘B`、会话摘要、真实文件搜索与预览、新网页空标签、右栏全屏与收起、四个缩放组合键及重置。Share、Changes 和外部网址加载待对应场景验证。

0.1.0 的 7 项单元与插槽注册测试及隔离 Web 交互验证也已通过，包含第三方面板、窄屏回退和停用恢复。
