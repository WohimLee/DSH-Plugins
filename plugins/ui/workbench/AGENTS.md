# Workbench 协作约定

从[工作台行为说明](README.md)确认当前入口。按本次改动选用下列分工，岗位可组合。

会话行尾（项目、Recents、活动列表）的图标统一经 [`SessionTail`](src/client/workspace/SessionTail.tsx) 放入以行尾为基准的命名网格槽位。增删或替换图标时，明确其主槽、共存槽和可见条件；不得用图标专用边距或绝对定位补齐。同步维护[宿主坐标断言](tests/host.mjs)，校验中心差不超过 0.5 CSS px；在各输入模式内，状态切换不得改变标题列宽。

| 改动 | 参与与交接 | 验收重点 |
| --- | --- | --- |
| 调整分区、项目、会话层级，或改变导航和移动流程 | UX 在实现前说明入口、目标选择、完成与取消后的焦点和选中项；前端核对宿主允许的操作后实现。 | 在 Desktop 从原入口走完操作，检查归属、选中项和返回路径。 |
| 新增视觉反馈，或调整侧栏密度、主题、缩放和窄窗布局 | UI 提供受影响视图、状态和视觉依据，前端实现后交给 UI 走查。 | 按受影响的窗口宽度、主题或缩放核对可读性、焦点和菜单位置。 |
| 将颜色、图标或间距恢复为已有设计 | 前端按现有样式修复并验证；需要重新决定外观时引入 UI。 | 在出现偏差的状态和主题下比对。 |
| 修复归组、置顶或重启恢复 | 熟悉宿主状态的工程师核对客户端存储与宿主数据的归属；需要独立复验时由 QA 重现原问题。 | 比对操作前后及重启后的状态。预期行为有歧义时交 UX 澄清。 |
