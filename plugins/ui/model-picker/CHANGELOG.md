# Changelog

## 0.2.5

- Overview 恢复品牌 Logo、当前账号 Usage 和用量明细。添加厂商下拉箭头增加内距。厂商行 Remove 在确认后解绑适配器管理的账号。Grok 的 Desktop 选项显示 Grok Bot 安装状态。

## 0.2.4

- 输入框的厂商、模型和 Effort 浮层随内容收口。单个显著超长的模型名用省略号显示，悬停、键盘聚焦或首次点按可查看全名。

## 0.2.3

- 模型管理侧栏增加 Models 标题，与宽窗工作台导航对齐。厂商概览改用单列连接行，账号与用量集中在厂商详情。

## 0.2.2

- 模型管理导航避开 macOS 窗控，页头与自动化任务对齐。窄窗导航自动换行，触屏入口保留 44px 点击高度。

## 0.2.1

- 输入框模型菜单按 Effort、厂商和模型逐级悬停展开，支持返回、搜索和窄窗停靠。模型账号标注已知的 Desktop 或 API 来源。

## 0.2.0

- 模型管理增加 Overview、添加厂商和已连接厂商的导航。概览卡片与厂商导航共用连接状态，点击卡片或厂商进入详情。
- 厂商详情按 Desktop 与 API 显示账号。添加厂商切换对应的安装与登录检测或 API 凭据表单，连通后刷新模型目录。
- Codex 和 Qoder 的独立桌面配置目录、Codex 与 DeepSeek 的命名 API 账号、Qoder PAT 和 Grok API 账号按各自路由管理。接入方式由实际厂商能力决定。

## 0.1.9

- 点击连接卡片可独立查看详情，概览卡片保持原位。Grok 使用原应用图标。
- 将用量移到模型管理卡片。可在卡片上选择账号，悬停或聚焦圆环查看额度或余额。输入框的模型选择器保留模型与账号选择。

## 0.1.8

- 聊天输入框与模型菜单恢复简洁显示，输入能力继续由适配器校验。

## 0.1.7

- 模型管理页显示各接入声明的输入能力、限制与推理档位，选择器同步显示当前账号的能力标签。

## 0.1.6

- 切换账号或模型时按目标模型的档位校验推理强度，只有仍有效的显式选择会被保留。

- 模型管理页使用响应式连接卡片、Codex 和 Qoder 原应用图标、按需展开的连接详情及可展开的模型目录。替换侧栏入口图标。

## 0.1.5

- 左侧栏增加模型管理页，显示可用模型和 Codex 本机登录状态，并提供厂商连接表单插槽。

## 0.1.4

- 双列浮层按厂商行数决定高度，切换厂商时模型列表在等高的右栏内滚动。

## 0.1.3

- 模型浮层贴着主菜单，优先显示在右侧，空间不足时贴左侧。界面缩放时保持边缘贴合。
- 缩窄厂商和模型两列，浮层高度随内容调整，长列表可独立滚动。

## 0.1.2

- 将原生模型菜单的两个模型入口合并为 Models，保留当前模型名称。鼠标悬停打开厂商选择器，宽窗口使用独立浮层。

## 0.1.1

- 悬停厂商时固定两列位置，模型较多时只滚动右侧列表。切换厂商或账号时，模型列表从头显示。

## 0.1.0

- 添加可展开的厂商模型列表、跨厂商搜索、账号选择，以及各厂商的额度和余额摘要。
