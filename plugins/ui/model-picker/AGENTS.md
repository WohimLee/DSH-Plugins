# Model Picker 协作约定

先按[模型选择与厂商接入说明](README.md)确认受影响的是原生模型菜单、管理页，还是厂商提供的连接组件。涉及适配器时，同时读取其插件约定；一次接入由一人跟进到约定的最终验收点。

| 改动 | 参与与交接 | 验收重点 |
| --- | --- | --- |
| 改变厂商、账号、模型的选择顺序，或引入新的连接流程 | UX 先说明如何进入、确认、取消和恢复；前端据此实现。更改卡片布局、浮层或焦点样式时由 UI 给出视觉依据。 | 从受影响入口选择和取消，核对当前会话的模型以及窄窗口下的操作。 |
| 接入厂商或改变连接状态 | 模型接入工程师负责认证、模型发布与撤回，并向前端说明可用状态和错误。需要变更连接组件或公共插槽时，与前端约定接口和刷新时机。 | 从管理页连接后打开选择器，检查模型可选；断开后检查该连接的模型撤回。要求真实推理时，以实际收到回复为验收点。 |
| 改变密钥存储、传递或日志边界 | 适配器实现者说明凭据流向，安全审查人员检查宿主凭据机制、界面回显及日志，反馈给实现者。 | 用合成凭据验证受影响路径；验证记录中仅写操作和结果。 |

新接入的厂商必须按 [Logo 光学尺寸规范](README.md#厂商-logo统一光学尺寸)登记品牌素材来源与适配尺寸，复用 `ProviderIcon`。验收以 24 × 24 CSS px 占位内的可见图案与现有厂商视觉分量相近为准，不能只核对图片元素宽高。

Overview 和厂商详情必须显示所选账号的当前 Usage，接入厂商可提供的额度、余额或计费数据，并覆盖刷新、账号切换及取数失败。厂商权限限制无法读取时，显示真实的不可用状态或官方查看入口。厂商行的 Remove 复用适配器解绑能力，并在执行前请求用户确认。

交付负责人分别记录界面验证、宿主目录变化和真实账号验证的结果。缺少账号而任务要求真实推理时，在[工作清单](../../../docs/work.md)保留待验项和恢复条件。
