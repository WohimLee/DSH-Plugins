# Changelog

## 0.1.3

- 聊天输入框与模型菜单恢复简洁显示，输入能力继续由适配器校验。

## 0.1.2

- 在模型加载时核对输入模态和目录字段来源，显示路由的图片支持和容量依据。

## 0.1.1

- 模型管理页使用统一的 Grok 连接卡片，支持展开设置和刷新连接状态。

## 0.1.0

- 使用当前密钥的模型目录提供推理档位和默认值。

- 使用 xAI API Key 连接 Grok，动态加载当前密钥可用的语言模型。
- 从模型管理或设置刷新、替换或断开连接，使用 DSH 凭据存储。
- 通过 xAI Responses API 支持流式推理和 DSH 工具调用。
- 模型发现和流式聊天支持 macOS 系统手动 HTTPS 代理。
