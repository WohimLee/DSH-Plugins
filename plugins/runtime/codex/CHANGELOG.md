# Changelog

## 0.1.8

- 聊天输入框与模型菜单恢复简洁显示，输入能力继续由适配器校验。

## 0.1.7

- 在载入模型时核对输入模态，支持通过宿主附件发送图片。

## 0.1.6

- 支持 macOS 手动 HTTPS 代理，使仅配置系统代理的 Desktop 能连接 Codex。
- 发布账号模型目录声明的有效默认推理强度，并在发请求前校验所选档位。

## 0.1.5

- 只在检测到本机 OAuth 登录时发布模型。登录文件与模型缓存变化会刷新 DSH 模型目录。

## 0.1.4

- 通过 Codex App Server 提供账号额度窗口和重置时间。

## 0.1.3

- 将开发基线更新至 DSH 0.2.2-rc.5，发布包声明兼容的 0.2.2 发行线范围。

## 0.1.2

- 修复配置 schema 自动生成空 models 数组导致无法发现本地模型的问题，并增加回归测试。
- 按 rc.3 的正式错误码契约分类失败，保持宿主重试策略可用。
- 隔离 Web 测试独立安装同版 DSH，避免根仓库旧版本依赖污染。
- macOS Desktop rc.3 已安装启用，选择器显示 Codex 分组及 10 个模型；真实账号推理待用户测试。

## 0.1.1

- 跟随本机 DSH Desktop 0.2.2-rc.3，对齐 engines.dsh、LLM peer、开发与隔离宿主验证版本。
- 使用桌面自带 Node 24.21.0 和实际打包依赖通过 10 项契约测试。

## 0.1.0

- 新增 Codex 模型提供者，读取本机 OAuth 登录与模型缓存，支持显式模型列表。
- 支持文本/推理流、工具调用往返、用量统计、取消与卸载清理。
- 增加模拟协议测试、真实 Cordis 契约测试和隔离 Web 安装验证。
- 真实账号推理和 Desktop 交互未验证；登录刷新由 Codex CLI 管理。
