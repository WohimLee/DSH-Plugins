# Changelog

## 0.1.8

- 修复 Qoder CLI 连接关闭与待发送请求重叠时，模型选择器可能导致 DSH 宿主退出的问题。

## 0.1.7

- 逐账号读取模型能力，按 SDK 视觉标志决定图片输入并显示来源。

## 0.1.6

- 在模型管理页和设置页引导用户通过浏览器授权，授权完成后自动加载模型。

## 0.1.5

- 按账号和模型读取推理档位与默认值，通过 SDK 模型策略将选中档位送入主对话请求。

- 在模型管理页的连接卡片中显示账号和 CLI 状态，展开后可管理账号。复用模型管理页的刷新入口。

## 0.1.4

- 将现有 Qoder 账号表单接入模型管理页。

## 0.1.3

- 账号按需添加，备注可选并可随时编辑。
- 保留旧版凭据和路由，修改备注时更新模型菜单的账号名称。

## 0.1.2

- 在 DSH 设置中绑定、更新或解绑两个 Qoder 账号的 PAT，凭据由 DSH 保存。
- 按账号查询可用模型目录。未连接或返回空目录时隐藏该账号的模型入口。

## 0.1.1

- 增加命名账号路由和可配置模型档位，通过 Qoder SDK 提供账号 Credits。

## 0.1.0

- 通过 Qoder Agent SDK 注册 Qoder 模型，支持文本与推理流、用量和取消。
- 通过进程内 MCP 声明 DSH 工具，并将模型提出的调用交还 DSH 审批和执行。
