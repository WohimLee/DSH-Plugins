# 安全边界

Host 插件在宿主进程中执行，不等于受到 Agent 工作区沙箱隔离。审核输入边界、文件范围、外部调用和权限；Client 不暴露原始 shell、Electron IPC 或凭据。

凭据通过 DSH 支持的凭据/配置机制取得，不写入源码、测试样本、locale、目录元数据或日志。仓库仅提供无秘密的 .env.example 时允许提交。

测试使用临时 DSH_HOME、合成身份与临时文件，不读取个人默认 DSH 会话或 .env。模型调用、消息发送、真实数据库写入和部署属于各任务明确的外部操作范围，脚手架检查不执行这些动作。

依赖安装只放开确需的构建脚本。插件发布前检查实际 tarball，第三方代码与许可证随实际引入核实，不将目录收录当作审计结论。

发现疑似秘密泄露先停止扩散，不在 issue、终端和交付说明中复述秘密。仓库尚无专门漏洞接收渠道，由维护者决定公开报告方式。
