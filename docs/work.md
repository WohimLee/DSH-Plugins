# 工作清单

同一克隆的所有会话共用**主工作树中的这份文件**。运行 `git worktree list --porcelain`，第一条 `worktree` 给出主工作树路径。从任意任务分支按该绝对路径读写 `docs/work.md`，未提交的登记也立即可见。任务分支提交业务改动时，清单条目由负责人在主工作树按任务范围单独暂存。不同克隆通过集成分支上已推送的清单交接。

实现开工、范围扩大或准备安装同一个包时，重读活动条目，按用户入口、接口和包名查交叉。在负责人栏填会话链接与实际分支，尚未开工可只填会话。写入范围具体到组件或接口。最后一栏写关联任务、先后顺序和下一位要做的事。按最近读到的行做局部更新；上下文已变就重读后重试。登记后再查一遍重叠项，先约定交接再写共享接口或安装同包。同一次交付的参与者共用一行。
