# 工作清单

同一克隆的所有会话共用**主工作树中的这份文件**。运行 `git worktree list --porcelain`，第一条 `worktree` 给出主工作树路径。从任意任务分支按该绝对路径读写 `docs/work.md`，未提交的登记也立即可见。任务分支提交业务改动时，清单条目由负责人在主工作树按任务范围单独暂存。不同克隆通过集成分支上已推送的清单交接。

**每次新需求先统筹。** 接收会话先拆成可独立验收的小任务，核对在途会话、子代理、分支和 Worktree，再决定由谁接续、哪些并行、哪些先交接。按用户授权登记目标、出处、参考材料和验收条件后派发，并记录实际接收者与状态。跨会话时在相关任务条目中指定本次主理 Agent。讨论中或范围未定时标「待澄清」，已授权推进且等待分配时标「待安排」。

开工、范围扩大、合并或准备安装同包时，重读活动条目，按入口、接口和包名检查交叉。负责人栏填会话链接、实际分支和 Worktree 名称或路径。写入范围具体到组件或接口，分工栏注明本次主理 Agent、派发对象、集成和 Desktop 负责人，最后一栏记录基线、依赖与交接顺序。按最近读到的行做局部更新，上下文已变就重读后重试。执行步骤见[并行开发与集成](development.md#并行开发与集成)。
