# 插件审查

先读根和目标目录 AGENTS、docs/testing.md、docs/compatibility.md。核实比较基线、完整 diff、真实调用方与最终产物；默认只读审查，不自行修复。

优先检查：Bundle patch 是否挂载正确入口；DSH peer 与 engines 是否匹配实际基线；Client 是否共享宿主框架实例；卸载和取消是否释放资源；输入、凭据与外部调用边界是否成立。追踪跨包消费者，不只读类型声明。

检查插件能否独立打包与安装，不能靠 monorepo 相邻文件成功。目录支持声明需要对应证据；类型检查、CLI 配置预览、真实加载和桌面交互分别判断。

仅报告可定位且有实际影响的发现，包含触发条件、影响与必要修复方向。无实质问题时说明未验证范围。自查与独立审查分别标识，不将自动检查称为独立审查。
