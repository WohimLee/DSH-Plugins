# 工作台项目侧栏按会话来源切换

状态：archived。2026-11-19 停止使用，原实现保留在 [插件归档](../../../archived/integrations/agent-sync/README.md)。下文记录归档前的设计与验证。

## 问题

连接器和工作台独立安装。用户需要在工作台项目侧栏顶部切换到已连接的 Agent Desktop 并浏览其项目、目录和会话。

## 决定

工作台的来源下拉控制项目侧栏视图。DSH 原生项目树保留已有排序与组织逻辑，Codex 树使用来源项目及工作目录。显式项目归属沿用 Codex 的项目 ID，缺少归属的会话落在未分组目录。

连接器注册已有面板插槽。其 Host 通过 DSH Typert Gateway 提供仅 Host 所有者可用的读取、同步、断开与打开操作。Client 发布可选 Cordis 服务 `agentSyncSessionsV1`，包含可订阅快照和 `open(id)`。快照的 `syncedAt` 为 `null` 时代表连接不可用。工作台跟随服务生命周期，失去连接时恢复 DSH 树。接口携带来源数据，工作台负责显示和来源选择。两个插件独立安装和版本化。

## 影响与验证

Codex 项目列表使用该版本 App Server 的实验接口。缺少接口的安装可按工作目录浏览会话。工作区路径来自 Codex 项目 roots 和会话工作目录。打开操作仅接受本次连接中已同步的 UUID，并在 macOS Host 上交给桌面应用处理。

2026-11-18，macOS，DSH 0.2.2-rc.3 与 Chrome 157.0.8103.79：组合测试安装工作台 0.4.0 和连接器 0.1.0 的独立 tarball。合成 Codex 数据验证了项目、路径和会话切换、刷新归档会话，以及断开和热停用时恢复 DSH。真实 Codex 账户读取和 DSH Desktop 点击打开仍待验收。
