# 实现任务完成时推送

状态：implemented。

## 问题

仓库已有插件、模板和 CI 配置，远端 main 仍只有初始化提交。当时的 Agent 规则要求每次提交与推送另行授权，开发任务可以在改动全部留在工作区时结束。

## 决定

由执行实现任务的 Agent 在交付时核实范围和验证结果，提交本次改动并推送到当前分支的上游。采用 [开发指南](../../../docs/development.md#提交与推送) 作为共同流程。文件保存或定时扫描无法判断哪些工作已经完成，也无法区分同一工作区里的不同任务，因此把触发点放在任务验收时。

## 影响与验证

现有 GitHub Actions 在收到适用的 push 或 pull request 事件后执行。交付时核对实际远端提交与 CI 状态。用户指定本地交付、分支流程或推送范围时，以任务要求为准。
