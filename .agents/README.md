## 维护

命令变化更新 AGENTS 与 development；宿主升级更新锁文件、模板和 compatibility，并复验。`bash .agents/scripts/validate.sh` 检查必要文件、相对文档链接、占位符、个人路径和技能入口；它不证明 agent 行为或业务能力。
